## PATENT SPECIFICATION 1 (PCT/IB2026/001001)

### Title
**METHOD, SYSTEM, AND COMPUTER PROGRAM PRODUCT FOR REAL-TIME KERNEL-LEVEL SYSTEM CALL DIVERSION VIA DYNAMIC BPF-LSM RETURN OVERRIDING AND VOLATILE EPHEMERAL SCRATCHPADS**

### Field of the Invention
The present invention relates generally to operating system security, and more specifically to transparent deception architectures utilizing in-kernel Extended Berkeley Packet Filter (eBPF) Linux Security Modules (LSM) to divert malicious mutating input/output operations into volatile ephemeral memory.

### Abstract
A method and kernel system for transparently neutralizing adversary payloads in real-time without terminating host processes. The system intercepts mutating system calls via a `bpf_override_return()` hook registered in a BPF-LSM architecture. Upon detecting malicious behavioral indicators or privilege escalation, the kernel shunts file write operations and socket connections into an ephemeral Copy-on-Write (CoW) userspace/kernel shared memory scratchpad. Synthetic file system metadata and microarchitectural timing delays are synchronized to maintain execution latency within a 100-cycle delta of native file system page cache latency, rendering the deception undetectable to automated anti-analysis heuristics.

### Claims (1 to 20)
1. A method for kernel-level deceptive containment of malicious software, comprising:
   (a) attaching at least one Extended Berkeley Packet Filter (eBPF) Linux Security Module (LSM) probe to a plurality of mutating kernel system calls;
   (b) intercepting, within kernel execution context, an invocation of a mutating system call originating from a target process;
   (c) querying an in-kernel shunting map indexed by process identifier (PID);
   (d) upon determining that said PID is designated for containment, invoking `bpf_override_return()` to bypass native kernel execution logic of said mutating system call;
   (e) redirecting payload data associated with said system call to an isolated ephemeral Copy-on-Write (CoW) memory scratchpad; and
   (f) returning a synthetic successful return code to said target process.
2. The method of claim 1, further comprising dynamically generating synthetic honeypot credentials within said CoW memory scratchpad.
3. The method of claim 1, wherein execution latency of said diverted system call is calibrated to match native ext4 page cache latency within a predetermined threshold of 100 CPU cycles.

## PATENT SPECIFICATION 2 (PCT/IB2026/001002)

### Title
**NEURO-SYMBOLIC FIRST-ORDER LOGIC SMT VERIFICATION GATE FOR PREVENTING HALLUCINATED ACTIONS IN AUTONOMOUS SECURITY AGENT SWARMS**

### Abstract
An autonomous multi-agent security triage architecture featuring an immutable formal verification gate. Causal threat hypotheses generated by large language models or deep graph learning agents are translated into First-Order Logic (FOL) satisfiability formulas. A Satisfiability Modulo Theories (SMT) solver evaluates said formulas against an immutable non-killable crown-jewel process whitelist and causal reachability Directed Acyclic Graphs (DAG). Containment directives that violate graph reachability or target protected processes are mathematically vetoed, eliminating false-positive service disruption.

### Claims (1 to 20)
1. A computer-implemented neuro-symbolic verification system, comprising:
   (a) an autonomous agent triage engine configured to output a candidate containment action and a natural language rationale;
   (b) a formal logic compiler configured to parse said candidate containment action into a First-Order Logic (FOL) proposition $\Phi$;
   (c) a formal methods verifier executing a Satisfiability Modulo Theories (SMT) solver;
   (d) an immutable policy specification encoding system invariants including a crown-jewel non-killable process list;
   (e) wherein said verifier evaluates $\Phi$ against said system invariants, and permits execution of said containment action if and only if $\text{SMT}(\Phi) \equiv \text{SAT}$.

## PATENT SPECIFICATION 3 (PCT/IB2026/001003)

### Title
**CONTINUOUS-TIME HETEROGENEOUS TEMPORAL GRAPH NEURAL NETWORK FOR STREAMING OPERATING SYSTEM TELEMETRY ANOMALY DETECTION**

### Abstract
A deep learning architecture for continuous streaming operating system provenance telemetry. The model introduces a continuous exponential decay function $\lambda_{ij} = \exp(-\gamma \cdot \ln(1 + \Delta t))$ modeling inter-event elapsed time $\Delta t$, integrated into a multi-head temporal attention mechanism over heterogeneous node types (Processes, Sockets, Inodes). An edge throttler reduces high-frequency repetitive events by an order of magnitude while preserving temporal innovation signals.

### Claims (1 to 20)
1. A method for continuous-time anomaly detection in streaming kernel telemetry, comprising:
   (a) receiving a continuous stream of kernel execution, socket, and file events;
   (b) updating a heterogeneous provenance graph having continuous time stamps;
   (c) computing an elapsed time $\Delta t$ between consecutive events on a directed edge;
   (d) calculating a continuous temporal decay factor $\lambda_{ij}$ as a logarithmic exponential function of $\Delta t$;
   (e) applying multi-head temporal attention across node embeddings weighted by said decay factor $\lambda_{ij}$; and
   (f) computing an anomaly innovation probability $\Delta \mathcal{H}$ representing deviations from baseline execution topology.

## PATENT SPECIFICATION 4 (PCT/IB2026/001004)

### Title
**TOPOLOGICAL PROMPT ISOLATION ENGINE FOR IMMUNIZING AUTONOMOUS AGENT SWARMS AGAINST INDIRECT PROMPT INJECTION**

### Abstract
A security architecture for autonomous security reasoning systems. Raw operating system strings, network payloads, and user commands are scrubbed and replaced with deterministic abstract cryptographic entity hashes and topological graph representations prior to prompt synthesis. This prevents malicious prompts embedded in adversarial filenames or network streams from executing unintended instructions within agent contexts.

### Claims (1 to 20)
1. A method for preventing indirect prompt injection in autonomous security agents, comprising:
   (a) ingesting raw provenance graph events containing string identifiers;
   (b) hashing said string identifiers into deterministic abstract entity identifiers;
   (c) stripping execution directives, special tokens, and control characters from said event data;
   (d) generating a sanitized topological graph representation consisting exclusively of typed relationship triples $(u, \text{REL}, v)$; and
   (e) delivering said topological graph representation to an LLM agent swarm devoid of raw string literals.
